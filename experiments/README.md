# Phase 0 starter experiments

Quick, M4-friendly scripts to sharpen intuition before committing to the full plan. Run in order.

Default model is **OLMo 2 1B** (`allenai/OLMo-2-0425-1B`) — small enough to download fast and exercise the full pipeline. Once everything passes on 1B, swap to OLMo 2 7B (`allenai/OLMo-2-1124-7B`) by editing the `MODEL_ID` constant in each script.

## Setup

```bash
cd experiments
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Gemma 2 9B setup (scripts 17, 18, 19, 19b, 20)

`google/gemma-2-9b` is a gated model. First-run setup:

```bash
huggingface-cli login   # paste an HF access token with model-access permission
# Then visit https://huggingface.co/google/gemma-2-9b in a browser and accept the license.
```

Once accepted, the script downloads ~18 GB on first run. Subsequent runs use the local cache (~/.cache/huggingface).

**Important:** Gemma 2 9B uses logit/attention soft-capping which overflows in fp16. The script forces `bfloat16` and includes a finite-value check on a sanity forward pass; do not switch dtype without rerunning the sanity check. PyTorch MPS supports bf16 from 2.3+; if MPS bf16 fails on your install, set `device = "cpu"` in `main()` (extraction will take ~3-4x longer but is otherwise correct).

| 16 | syntactic-confound stress test | **The definitive Phase 0 test of the arity-attractor claim.** External-review-driven: addresses the prefix-vs-infix syntactic-position confound that scripts 7-15 could not rule out.
